# 分岔之匣 · The Forking Deck

> **写作可能性裂变引擎** · 为写作者的思维破障，输入一句话，就地分裂出不可预测的叙事方向。

---

## ✨ 核心理念 (Philosophy)

许多 AI 写作工具之所以让创作者感到索然无味，是因为它们试图“代笔”——替人写完整段甚至整章，结果往往滑向平庸可预测的陈词滥调。

**《分岔之匣》不是代笔者，而是创作者的“思维棱镜”与“破障器”：**
- **写作者负责投掷起点**：在文稿中写下一句话。
- **系统负责折射张力**：针对这束单色光，从多个截然不同的文学张力维度（预设打破、感官深潜、外部危机、荒诞诗性）分裂出接下来的可能发展走向。

---

## 🚀 特性 (Features)

1. **Final Draft 风格沉浸式文稿画布**
   - 极简、纯粹的剧本文稿纸设计，白纸黑字，Courier 打字机排版，杜绝任何喧宾夺主的仪表盘干扰。
2. **随光标游动的微小触发器**
   - 打字时，一个小巧的 `🎴 抽卡` 气泡紧紧跟随在输入光标旁。
   - 写完一句后，**直接按键盘 `Tab`** 即可就地抽卡。
3. **两种抽卡交互形态（自由切换）**
   - ⚡️ **简单光标模式**：就地在光标下方弹出精简小菜单，零中断打字心流。
   - 🎴 **塔罗动画模式**：暗金塔罗牌在 3D 空间中悬浮自转凝聚，演算完成瞬间清脆发牌并分裂为四张独立牌面（罗马数字标号：I·反转、II·深潜、III·危机、IV·超验）。
4. **四大张力家族 × 十二个子维度**
   - 每次抽卡从四个家族中各抽一个子维度，同一句话每次都可能裂向不同方向：
     - 反转：预设打破 / 身份错位 / 因果倒置
     - 深潜：感官印记 / 记忆闪回 / 内心裂缝
     - 危机：外部突入 / 倒计时 / 失控连锁
     - 超验：荒诞诗性 / 物性苏醒 / 时空褶皱
   - 发给模型的不只是一句话，还有光标前的前文（约 1000 字）、光标后的后文与文稿标题，续写会沿用已有的人物、人称与文体。
5. **非破坏式平滑续写（Non-destructive Append）**
   - 选卡插入时精准锁定文末锚点，以适当标点与空格无缝追加到已有文字之后，**绝对不会覆盖、替换任何已写正文**。
6. **本地代理与大模型支持**
   - 内置 Node.js 原生轻量代理，支持 DeepSeek API 以及任何 OpenAI 兼容接口。
   - 彻底避开浏览器 CORS 跨域限制与广告插件拦截。
   - 未配置 API Key 时提供离线引子：按同样的维度给出句首提示（人称跟随前文），供你自己接着写下去。

## 🛠️ 快速启动 (Quickstart)

环境要求：安装有 [Node.js](https://nodejs.org/) (v18+)

```bash
# 1. 克隆代码仓库
git clone https://github.com/Polygethes/the-forking-deck.git
cd the-forking-deck

# 2. 启动本地服务（原生零额外 npm 依赖）
npm start

# 3. 访问浏览器
# http://127.0.0.1:4321
```

在界面右上角点击设置，填入你的 DeepSeek API Key（仅保存在本地浏览器 LocalStorage），即可开启全量真实 AI 叙事推理。
